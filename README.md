Zoo Management System

This is a terminal based Zoo Management system that I created to further develop my skills with Java. 
This program is indented to be used by the Zoo Keeper.

How to Run the Code: 
1. Download IntelliJ IDEA
2. Create a new project
3. Copy the files into the Src folder.
4. Then move the .txt files into the projects main file (Not the src); 
5. Then run the zoo App File. 

Features:
1.Adding of Animal to the Zoo
2.Removal of Animal from the Zoo
3.Edit the Details of the Animal
5.Search through all the animals
6.Get the daily reports of the animals
7.Get the health Checks for each animal
8.Sorts each animal into their type
9.Records the records of the animals
10.Edit Zoo Details
11.Change Zoo details
13. Delete Zoo Details
